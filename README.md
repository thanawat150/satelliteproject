# Free Satellite Assistant for Antigravity

ผู้ช่วยเลือกและเตรียมข้อมูลดาวเทียมฟรีสำหรับผู้ใช้ที่ไม่จำเป็นต้องรู้ชื่อดาวเทียม แบนด์ หรือผู้ให้บริการ

## หลักการ

ผู้ใช้บอกเพียง:

1. พื้นที่อยู่ที่ไหน
2. อยากรู้อะไร
3. ต้องการดูช่วงเวลาใด

ระบบใช้กฎเลือกข้อมูลก่อน และเรียก AI เฉพาะกรณีที่ตีความไม่ได้จริง เพื่อลด Token และลดการถามตอบซ้ำ

## ตัวอย่างคำสั่ง

```bash
python scripts/plan_job.py --goal "อยากรู้ว่าป่าชายเลนแปลงนี้ยังสมบูรณ์ไหม"
```

ตัวอย่างผลลัพธ์:

```json
{"intent":"vegetation_health","confidence":0.8,"needs_clarification":false,"sources":["sentinel-2-l2a"],"fallbacks":["hls","landsat-c2-l2"],"outputs":["rgb","ndvi","ndmi","preview"]}
```

## คำสั่งที่รองรับเบื้องต้น

- ดูภาพพื้นที่ล่าสุดหรือทำพื้นหลังแผนที่
- ตรวจสุขภาพพืช ต้นไม้ หรือป่า
- ตรวจการเปลี่ยนแปลง การบุกรุก หรือการถางป่า
- ตรวจน้ำท่วม น้ำขัง และความชื้น
- ดูอุณหภูมิพื้นผิว
- ดูข้อมูลย้อนหลังและแนวโน้มหลายปี
- ดูความสูง ความลาดชัน และภูมิประเทศ
- สำรวจพื้นที่เบื้องต้นเมื่อผู้ใช้ยังไม่แน่ใจ

## โครงสร้าง

```text
SKILL.md                    กติกาสั้นสำหรับ Agent
config/intent_rules.json    กฎแปลงภาษาคนเป็นงานดาวเทียม
config/providers.json       รายละเอียด Provider โหลดเมื่อจำเป็น
scripts/plan_job.py         วางแผนโดยไม่เรียก LLM
```

## แนวทางสำหรับ Antigravity

ให้ Antigravity อ่าน `SKILL.md` ก่อน จากนั้นเรียก `scripts/plan_job.py` เพียงครั้งเดียวต่อหนึ่งงาน เมื่อ confidence ตั้งแต่ 0.75 ให้ใช้แผนนั้นต่อทันที งานค้นหา STAC ดาวน์โหลด ตัดภาพ คำนวณดัชนี QA และสร้าง Preview ควรทำด้วย Python โดยไม่ส่ง log หรือ raster กลับเข้า context ของโมเดล

## สถานะ

เวอร์ชันนี้เป็นแกนวางแผนงานแบบประหยัด Token ขั้นต่อไปคือเพิ่ม Provider adapters สำหรับ Earth Search, Planetary Computer, Copernicus Data Space, USGS และ NASA พร้อมระบบ clip-to-boundary และ manifest กลาง
