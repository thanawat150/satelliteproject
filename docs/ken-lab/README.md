# KEN LAB — Creative & Geo Studio (v1)

**One workspace, six tools.** Runs as a static GitHub Pages site without Google Login, Supabase, AI API keys, or paid API access.

## Available now
- **Content Factory** — Enter a topic (20/40/60s), select category and presenter, generate an explicitly labelled *template draft* with five editable scenes including overlay text, voice-over and motion visual types. Data is editable and saved in browser localStorage. No claim that templates were generated by external AI.
- **Auto Video Studio** — Canvas-created animated vertical 9:16 videos. Real-time preview, scene timeline, optional voice and licensed music upload, MediaRecorder export at 30fps (720×1280 or 1080×1920). Exports MP4 **only when supported by that browser's MediaRecorder**; otherwise exports WebM. Export takes about the full clip duration; leave tab open.
- **GeoAI Learning Lab** — Five interactive general GIS/remote-sensing questions.
- **Satellite Intelligence** — A link to the existing working Satellite Project.

## Start
1. Open `index.html` (modern Chromium recommended), or serve directory using `python -m http.server 8000`.
2. Go to **Content Factory** → enter a topic → generate outline.
3. Edit all scenes and narration, then click **ส่งไป Video Studio**.
4. Press play to preview. Optional: add WAV/MP3 voice over and licensed music.
5. Export: the browser generates an actual video; extension `.mp4` or `.webm` depends on MediaRecorder support. Clips without uploaded sound export silently.
6. Use **สำรองข้อมูล** to save a JSON of editable scripts. Browser data lives in localStorage and is not synchronized to other machines.

## Production notes
- The text creator is **not** connected to a language-model API. It uses an editable five-scene structure and never fabricates satellite-analysis statistics.
- 1080×1920 rendering may be slow on weaker devices; use 720×1280 first.
- Audio upload is used only during render in this browser and is not uploaded or persisted; select again after reload.
- MediaRecorder exports video in real time; Chrome/Edge browsers generally offer WebM, others may offer MP4. No browser conversion is claimed.
- Video generation is original Canvas procedural motion, not imported stock footage or slides.
- This is a **local-first prototype**, not a hosted backend. No external data sync, posting, or account authorization.
- Repository path on GitHub Pages: `docs/ken-lab/`, isolated from the old Satellite portal.

## Privacy / license
- No analytics or tracking services are used by our JavaScript. A Google Fonts CSS import is optional; the system can use local Thai fonts as fallback.
- Content input and character descriptions persist in browser localStorage. Keep downloaded backups private if they contain personal information.
- Supply only media you own or have rights to publish.
